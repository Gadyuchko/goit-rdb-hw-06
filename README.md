Final project on the `infectious_cases` dataset. Everything is in `final_project.ipynb`, screenshots of tables, queries and results are in `screenshots/`.

## Data

`infectious_cases.csv` with infectious disease numbers by country (entity) and year. The file is in `data/`,
if it's missing the notebook downloads it.

## Running it

Notebook runs in Colab or localy. PostgreSQL runs through `pgserver`, nothing else to install.
